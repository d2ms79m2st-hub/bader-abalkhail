# بدر أبا الخيل — معاينة تفاعلية للموقع

معاينة محلية فقط (localhost): لا نشر، ولا دومين، ولا استضافة، ولا دفع، ولا قاعدة بيانات، ولا ربط بالمتجر.

## التشغيل

- انقر مرتين على `تشغيل-المعاينة.bat`، أو من الطرفية داخل هذا المجلد:

```bash
npm run dev
```

ثم افتح http://localhost:5173

**على iPhone:** يجب أن يكون الجوال والكمبيوتر على شبكة الواي فاي نفسها. افتح في Safari عنوان `Network` الذي يظهر في الطرفية، مثل `http://192.168.x.x:5173`.

## المشاهد

| # | المشهد | التقنية |
|---|---|---|
| 0 | شاشة افتتاحية بالشعار الرسمي وتقدم التحميل | GSAP + clip-path |
| 1 | فيلم افتتاحي يتقدم مع التمرير، ونصوص متزامنة مع اللقطات، وجزيئات دخان | تسلسل إطارات على Canvas + ScrollTrigger scrub |
| 2 | مسرح العطور الأربعة (٧٥ ملي) مع انتقال قناع بين الصور | قسم ثابت (sticky) + خط زمني |
| 3 | شريط خشب العود الأفقي، مع Parallax داخل البطاقات وميلان حسب سرعة التمرير | تمرير عمودي ← حركة أفقية |
| 4 | دهن العود والمسك: طبقات صور بعمق مختلف، ومعاينة تتبع المؤشر | Parallax |
| 5 | المباخر: صورة تتوسع من بطاقة إلى ملء الشاشة، ثم شبكة المنتجات | clip-path scrub |
| 6 | البوكسات: بطاقات ثلاثية الأبعاد تميل مع المؤشر، ومحتويات من الوصف الرسمي | 3D tilt |
| 7 | الختام: الشعار و«عبق يفوح» | — |

عند النقر على أي منتج تُفتح نافذة فيها معرض صوره، واختيار الوزن أو الحجم يحدّث السعر.

## الأصول والبيانات (كلها رسمية)

- **الشعار:** نسخة مطابقة بايت ببايت من `نماذج/assets/logo/لوقو المحل.jpg`، ويتحقق السكربت من البصمة.
- **الخطوط:** Thmanyah Serif Display وThmanyah Sans من الحزمة الرسمية `Thmanyah-Font-Family (1).zip`.
- **الصور والأسعار والأوصاف:** من `Store_Catalog/`، أي لقطة المتجر بتاريخ 2026-10-28. الأسعار قد تكون تغيرت منذ ذلك التاريخ.
- **النصوص:** أسماء الأقسام والمنتجات وأوصافها كما في المتجر، و«عبق يفوح» من عبوة العطر الرسمية. لم تُضَف أي شعارات تسويقية جديدة.
- **الفيلم الافتتاحي:** مبني حاليًا من ٤ صور رسمية للمتجر، مع حركة كاميرا وانتقالات ضبابية، لأنه لا يوجد فيديو منتج سينمائي رسمي بعد.

## استبدال الفيلم بفيديو رسمي

```bash
npm run frames -- "C:/المسار/الفيديو.mp4"
```

يحوّل الفيديو إلى 160 إطارًا بنسختين: كمبيوتر (1280×720) وجوال (720×1280). يقرأها الموقع تلقائيًا، والفيديو الأصلي لا يُعدّل. ولتغيير عدد الإطارات: `--count 200`.

## إعادة بناء الأصول من الكتالوج

```bash
npm run assets
```

## الأداء

- تُحمّل الإطارات على طبقات: كل 16 إطارًا، ثم 8، ثم 4، ثم 2، ثم 1. يبدأ التمرير فورًا وتمتلئ الفجوات في الخلفية.
- يحمّل الجوال نسخة طولية خاصة به، وتُحدّ دقة Canvas عند ‎2x.
- صور المنتجات نسخ WebP مصغّرة (حتى 1100px) بدل الأصل الذي يصل إلى 3MB، وتُحمّل عند الحاجة (lazy).
- التمرير الناعم (Lenis) يعمل على الكمبيوتر فقط، والجوال يستخدم التمرير الأصلي لأنه الأنعم على iPhone.
- عند تفعيل «تقليل الحركة» في النظام تُوقف الحركات الزخرفية.
